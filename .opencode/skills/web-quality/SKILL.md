# Web Quality

## Бюджеты (не превышать)

| Метрика | Цель | Предел |
| --- | --- | --- |
| LCP | ≤ 2.0 s | 2.5 s |
| INP | ≤ 150 ms | 200 ms |
| CLS | ≤ 0.05 | 0.1 |
| JS (gzip) на страницу | ≤ 150 KB | 400 KB |
| CSS (gzip) | ≤ 40 KB | 80 KB |
| Шрифты | ≤ 2 файла, ≤ 120 KB | 3 файла |

Мерить так: `pnpm build && pnpm preview`, затем Lighthouse в mobile-режиме с throttling. Отдельно проверять самую тяжёлую страницу (обычно статья с изображениями).

## Доступность (WCAG 2.2 AA) — чек-лист

- [ ] Один `h1`, иерархия `h2/h3` без пропусков.
- [ ] `alt` осмысленный; декоративные изображения — `alt=""`.
- [ ] Контраст текста ≥ 4.5:1, крупного ≥ 3:1.
- [ ] Всё управляется с клавиатуры, `:focus-visible` виден.
- [ ] Ссылки — `<a>`, действия — `<button>`, не `<div onclick>`.
- [ ] Формы: `<label for>`, ошибки текстом, не только цветом.
- [ ] `lang` на `<html>`, уникальный `title` на каждой странице.
- [ ] `aria-*` только при необходимости — нативный HTML лучше.
- [ ] `prefers-reduced-motion` учитывается.
- [ ] Skip-link в начале страницы.

## Производительность

- Изображения: `astro:assets` / `<Image>`, `width`+`height` или `aspect-ratio`, `loading="lazy"` ниже первого экрана, hero — `loading="eager"` + `fetchpriority="high"`.
- Шрифты: self-host, `font-display: swap`, `preload` только для основного.
- Никаких блокирующих сторонних скриптов в `<head>`; аналитика — `defer`.
- Острова — только там, где действительно нужен интерактив.
- Не импортировать целую библиотеку ради одной функции.

## Семантика

`header/nav/main/article/section/aside/footer`, `time datetime`, `figure/figcaption`, осмысленные тексты ссылок («Читать про X», а не «Подробнее»).

## Проверка

```sh
pnpm build
pnpm astro check
npx @biomejs/biome check .   # или eslint + prettier
```

Дополнительно: axe DevTools на 3 ключевых страницах, проверка на 320 px, проверка с отключённым JS.

## Что считать блокером релиза

Красный Lighthouse по Accessibility или SEO, ошибки в консоли, горизонтальный скролл, недоступная с клавиатуры навигация, LCP > 2.5 s на мобиле.
