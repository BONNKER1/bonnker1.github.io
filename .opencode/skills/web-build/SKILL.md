# Web Build

## Когда использовать

Новый сайт, блог, лендинг-раздел, добавление страниц, смена стека или структуры проекта.

## Принципы

1. **Сначала бриф, потом код.** Без цели, аудитории и CTA любая вёрстка — угадывание.
2. **Server-first.** Статика или SSR по умолчанию; клиентский JS — только для интерактива.
3. **Контент отдельно от кода.** Markdown/MDX-коллекции, а не тексты внутри компонентов.
4. **Маленькие шаги.** Одна страница или компонент за итерацию, после каждой — сборка.
5. **Проверка — часть работы.** «Готово» значит: `build` проходит, ссылки живые, Lighthouse в бюджете, консоль чистая.

## Процесс

### 1. Бриф (5–10 строк)

- Цель сайта и главное действие посетителя (один CTA).
- Аудитория и язык.
- Список страниц (старт: 3–7) и разделы блога.
- Есть ли готовый контент, логотип, брендбук.
- Хостинг и домен.

Если данных нет — задай вопросы через инструмент `question`. Не выдумывай факты о бизнесе.

### 2. Стек

Прочитай `references/stack-decision.md`. По умолчанию для контентного сайта/блога:
**Astro + Tailwind CSS + TypeScript**, пакетный менеджер `pnpm`.
Отступай от дефолта только по явной причине из таблицы.

### 3. Каркас

```
src/
  pages/            # маршруты
  layouts/          # BaseLayout, PostLayout
  components/       # Header, Footer, Card, Hero...
  content/          # коллекции: blog/, pages/
  styles/           # tokens.css, global.css
  lib/              # seo.ts, утилиты
public/             # favicon, robots.txt, og-изображения
```

- Один `BaseLayout`: `<head>`, SEO-пропсы, шрифты, skip-link, header/footer.
- Контент-коллекции через `src/content.config.ts` со схемой (zod).
- Никаких страниц-заглушек с lorem ipsum в финале.

### 4. Сборка страниц

Порядок: главная → ключевые разделы → блог-лист → статья → 404 и служебные.
Для каждой страницы: семантические теги, один `h1`, метаданные через `lib/seo.ts`, состояния hover/focus, мобильная вёрстка от 320 px.

### 5. Проверки перед «готово»

```sh
pnpm build        # без ошибок и предупреждений схем
pnpm astro check  # типы
```

Затем пройди `references/launch-checklist.md` и навык `web-quality`.

### 6. Деплой

Статика → Cloudflare Pages / Netlify / Vercel. Preview-деплой на каждый PR, `noindex` на превью. После запуска — sitemap в Search Console.

## Частые ошибки

- Тяжёлый React-остров на всю страницу ради меню.
- Тексты внутри компонентов — контент невозможно редактировать.
- SEO и доступность «на потом» — переделка дороже.
- Три шрифта и пять библиотек иконок.
- Проверка только на своём мониторе.
