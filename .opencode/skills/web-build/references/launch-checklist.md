# Чек-лист запуска

## Контент

- [ ] Нет lorem ipsum, заглушек и битых ссылок.
- [ ] Все страницы из брифа существуют и доступны из навигации.
- [ ] Тексты вычитаны: единый стиль, термины, формат дат и чисел.
- [ ] 404 и пустые состояния оформлены.

## Техника

- [ ] `pnpm build` без ошибок и предупреждений.
- [ ] Типы проходят (`astro check` или `tsc --noEmit`).
- [ ] Консоль браузера чистая на 5 ключевых страницах.
- [ ] Внешние ссылки проверены (ручной обход или link-checker).
- [ ] `sitemap.xml` и `robots.txt` отдаются, sitemap корректен.
- [ ] `noindex` только на превью и служебных страницах.

## Качество

- [ ] Lighthouse mobile: Performance ≥ 95, Accessibility ≥ 95, Best Practices ≥ 95, SEO 100.
- [ ] Проверено 320 / 768 / 1024 / 1440 px.
- [ ] Контент читается без JS.
- [ ] Клавиатура проходит всю страницу, фокус виден.

## Деплой

- [ ] HTTPS, один канонический вариант домена (http/www редиректят).
- [ ] Домен совпадает с `canonical` и `og:url`.
- [ ] Preview-деплой на PR.
- [ ] Формы проверены реальной отправкой.
- [ ] Аналитика не блокирует рендер.
- [ ] Sitemap отправлен в Search Console.
