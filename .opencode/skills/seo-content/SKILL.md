# SEO & Content

## Метаданные на каждой странице

- `title` 50–60 символов, уникальный, польза впереди.
- `description` 140–160 символов, без воды.
- `canonical` — абсолютный URL.
- Open Graph + Twitter: `og:title`, `og:description`, `og:image` (1200×630), `og:type`, `og:url`.
- `robots` — `noindex` на превью и служебных.

Реализация — один `src/lib/seo.ts`: принимает объект, возвращает пропсы для `<head>`. Никаких копий тегов по страницам.

## Структура URL

`/blog/kak-vybrat-stek/` — читаемые слаги без дат и ID. Один раздел — один префикс. На вложенных страницах — хлебные крошки.

## JSON-LD (обязательный минимум)

- Главная: `Organization` + `WebSite`.
- Вложенные страницы: `BreadcrumbList`.
- Статьи: `Article` / `BlogPosting` с `datePublished`, `dateModified`, `author`.
- FAQ-блоки: `FAQPage`.

Шаблоны — `references/schema-examples.md`. Проверять в Google Rich Results Test.

## Контент статьи

- `h1` = запрос пользователя, а не название компании.
- Первый абзац отвечает на вопрос за 2–3 предложения.
- `h2` — из подзапросов; сравнения — таблицей или списком.
- 2–5 внутренних ссылок на релевантные материалы.
- Видимая дата публикации и обновления.
- `alt` описывает содержимое, а не «image1».

## Техническое

- `sitemap.xml` через `@astrojs/sitemap`, `robots.txt` со строкой `Sitemap:`.
- 404 отдаёт статус 404; редиректы 301, без цепочек.
- Один вариант URL: либо с trailing slash, либо без.
- Перелинковка «хаб → кластер»; в футере не сваливать все ссылки.
